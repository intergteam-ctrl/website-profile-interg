Kebijakan Privasi – Juragan Dapur Gizi

Berlaku sejak: 8 Oktober 2026

Juragan Dapur Gizi ("game") dibuat oleh InterG Studio (CV Inter G Queen Bumindo). Kebijakan ini menjelaskan data apa yang terlibat saat kamu memainkan game ini di Android.

1. Data yang disimpan di HP kamu

Kemajuan permainan (nama usaha katering yang kamu ketik, koin, bintang, upgrade, dan pengaturan suara) disimpan hanya di HP kamu. Data ini tidak dikirim ke server kami. Menghapus data aplikasi atau mencopot pemasangan game akan menghapusnya.

2. Iklan (Google AdMob)

Game ini gratis dan menampilkan iklan dari Google AdMob. Iklan berhadiah hanya tayang jika kamu memilih untuk menontonnya. Untuk menayangkan iklan, mengukur kinerjanya, dan mencegah penipuan, SDK Google Mobile Ads dapat mengumpulkan:

  • alamat IP (dapat dipakai memperkirakan lokasi umum),
  • interaksi dengan aplikasi dan iklan (misalnya aplikasi dibuka, ketukan, tayangan video),
  • informasi diagnostik (misalnya waktu buka aplikasi dan kinerja),
  • ID perangkat seperti ID iklan Android dan app set ID.

Data ini dikirim terenkripsi (TLS) dan diproses oleh Google sesuai Kebijakan Privasi Google dan cara Google memakai data dari aplikasi mitra . Kamu dapat menyetel ulang atau menghapus ID iklan di Setelan Android → Google → Iklan.

3. Analitik (Google Analytics for Firebase)

Jika aktif, game mengirim data penggunaan seperti hari yang dimainkan, bintang yang diraih, dan iklan yang ditonton, beserta ID instans aplikasi. Data ini dipakai untuk memperbaiki game dan tidak dipakai untuk mengenali kamu secara pribadi. Nama usaha yang kamu ketik tidak ikut dikirim.

4. Anak-anak

Game ini ditujukan untuk pemain berusia 13 tahun ke atas. Kami tidak dengan sengaja mengumpulkan data pribadi anak di bawah 13 tahun.

5. Berbagi data

Kami tidak menjual data pribadi. Data hanya diproses oleh penyedia layanan di atas (Google) untuk tujuan yang dijelaskan.

6. Perubahan

Kebijakan ini dapat diperbarui. Tanggal berlaku di atas akan diubah setiap kali ada perubahan.
